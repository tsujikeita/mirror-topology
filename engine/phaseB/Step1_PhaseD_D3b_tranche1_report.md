- **主張するもの**：(i) 追加配置（spec v2 `mode=generate_D3b` の 81）の評価 bank（batch 0：N₀＝10⁶ 行，batch 1：3N₀ 行；float64 のみ）と fitting bank（N_fit＝2×10⁵）を，**D-2 と同一の数値経路**（`d2_rng.generate_from_latent`：同 CRN 表・同 group・同 key・同 UID 順・同 kernel `D_batch`／`scan`）で，束縛だけを tranche 2b の受入れ依存（spec v2・108 位置 receipt・検証済み `TwelveContext`）に替えて生成する生成器／検証器／intake；(ii) D-2 script と同じ構造の生成 script（preflight gate 13・producer binding・`--reuse-root`・registry・`D3B_PASS`）と family／size 単位の Colab launcher；(iii) TEST-ONLY kernel での小規模試験（scale 0.001〜0.002）と script の self-test。
